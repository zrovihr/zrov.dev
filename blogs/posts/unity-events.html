Unity Events

In order to easily throw around resposibility to other scripts, we can use Events. I will show you how to handle it in c++ but this time lets dive into Unity Events.

UnityEvent onDamageReceived;

void OnTriggerEnter(Collider other)
{
    if (other.CompareTag("Enemy"))
    {
        onDamageReceived.Invoke(); //Tell all other codes that we got hit
        Destroy(other.gameObject);
    }
}

Then inside the other scripts such as BattleManager

void Start()
{
    onDamageReceived.AddListener(ShakeCamera);
}

void ShakeCamera()
{
    // Implementation
}

We register ShakeCamera function into onDamageReceived Event.
which means, every time the player gets hit, ShakeCamera will be called!
The responsibility to ShakeCamera when damaged has been moved to BattleManager.
With this, we can make functions spread across the code and less God classes.
